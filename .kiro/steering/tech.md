# Technical Stack & Rules

## Technology Stack

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables
- **Vanilla JavaScript**: No frameworks or libraries

## Constraints

- ❌ **No frameworks**: React, Vue, Angular, etc.
- ❌ **No backend**: Everything runs client-side
- ❌ **No build tools**: No webpack, Vite, or bundlers
- ❌ **No tests**: Keep it simple for this project
- ❌ **No external dependencies**: No CDN imports or npm packages

## Data Storage

- **Local Storage only**: All user data persists in the browser's Local Storage API
- Data is local to the browser and device

## Browser Support

Must work correctly in:
- Chrome (latest)
- Firefox (latest)
- Edge (latest)
- Safari (latest)

## Code Quality

- Write clean, readable code
- Use meaningful variable and function names
- Add comments where logic is complex
- Keep functions small and focused
- Follow consistent formatting
